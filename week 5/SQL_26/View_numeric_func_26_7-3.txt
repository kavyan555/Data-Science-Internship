Aggregate functions:

the functions which will combine values of a multiple rows to produce one result

1.count:helps to count the number of rows
2.sum:helps to add all the values in a column
3.min:helps to show the min value in a column
4.max:helps to show the max value in a column
5.avg:helps to calculate the average value

group by with aggregate functions:

it is used to group rows and apply aggregate functions to
each group
